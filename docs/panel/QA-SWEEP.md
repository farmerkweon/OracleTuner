## 결함 목록 (심각도 순 · 재현 절차 포함)

### D01 [높음] 튜닝 이력 검색창이 타이핑에 반응하지 않는다
- **재현**: 접속 → [튜닝 이력] → 검색창에 `ZZZZQQQQ` 입력 (Enter 안 누름) → 3초 대기
- **기대**: 0건으로 걸러짐 (SQL 목록 검색은 그렇게 동작)
- **실제**: `1건 · 태그 qa(1), sweep(1)` 그대로. 레코드도 그대로 표시됨. Enter 를 눌러야만 0건이 됨
- **대조군**: `#sqls-search` 에 `NVL` 입력 시 Enter 없이 **즉시** 10건→1건, `ZZZZNOTHING` → 0건
- **근거**: 로그 23:21:35 `DEFECT CONFIRMED`, `93-history-search-nomatch.png`, `94-sqls-search.png`

### D02 [높음] 튜닝 후보 배지 숫자가 보이지 않는다 (글자색 = 배경색)
