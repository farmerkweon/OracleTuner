## 대비비 측정 방법 (재현 가능하게)

`.btn` 에 `transition` 이 걸려 있어 테마를 바꾸자마자 `getComputedStyle` 을 읽으면 전환 중간값이 잡힌다.
헤드리스 크롬은 `requestAnimationFrame` 이 돌지 않아 rAF 대기도 못 쓴다. 그래서 측정 하네스는

```
*,*::before,*::after{transition:none !important;animation:none !important;}
```

를 주입하고 대기는 전부 `setTimeout` 으로 했다. hover 상태는 CSS 로 흉내내지 않고 **실제 마우스를
올려서**(`page.hover`) 만들었다. "수정 전" 값은 옛 버전을 따로 띄운 게 아니라 **같은 화면에 수정 전
CSS 를 런타임에 되돌려 주입**해 측정했다 — 같은 조건에서 전/후를 비교하기 위함이다.

### D02 [높음] 튜닝 후보 배지 숫자가 보이지 않는다 ✔ (8테마 전부)

| | 내용 |
|---|---|

### D03 [높음] 토너먼트 실행 후 [토너먼트 실행] 버튼 글자가 사라진다 ✔ (8테마 전부)

|---|---|

| **검증** | 실제 목록 순서 |


| **조치** | `max="2000000"` 으로 서버와 범위를 맞춤. |

| **검증** | `checkValidity()` → **`true`** (수정 전 `false`, `"The nearest valid value is …"`)<br>※ 중간에 `step="1000"` 을 넣었더니 `min=1` 기준으로 `2000000` 이 다시 무효가 되어 되돌렸다. |

## 4. 원인만 규명하고 손대지 않은 것

### D22 [중간] 브라우저를 닫았다 다시 열면 접속이 풀린다 — **원인 확정 / 조치는 판단 요청**

- **원인(확정)**: `web/js/api.js:82·98·103` 이 세션 키를 **`sessionStorage`** 에 넣는다.
  `sessionStorage` 는 **탭 수명**에 묶인다 — F5 는 살아남고 창을 닫으면 사라진다.
  QA 가 관찰한 "F5 는 유지, 창 닫으면 풀림"과 정확히 일치한다.
- **손대지 않은 이유**: `localStorage` 로 바꾸면 **DB 세션 키가 브라우저 재시작 후에도 디스크에 남는다.**
  접속정보를 다루는 도구에서 이건 화면 편의가 아니라 **보안 정책 결정**이다. 서버측 세션 수명·무효화
  정책과 함께 정해야 하고, 화면 담당이 단독으로 바꿀 사안이 아니라고 판단했다.
- **선택지**: ① 현행 유지 ② `localStorage` + 서버측 만료(예: N시간) + 트레이 종료 시 무효화
  ③ 재접속 시 비밀번호만 다시 받는 "빠른 재접속" 화면.
