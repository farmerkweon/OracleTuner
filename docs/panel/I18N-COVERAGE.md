### 2-1. 측정 방법과 제외 기준

- `web/js/**` 의 `.js` 18개 파일을 **문자열 상태기계로 토큰화**(주석·정규식 리터럴을 정확히 제거)한 뒤,

## E. 동작 호환성에 관해 밝혀 둘 것

1. **언어 전환 즉시 반영을 위해 모듈 상수를 함수로 바꿨다.**
   `history.js` 의 `STATUS_LABEL`/`VERDICT_LABEL`, `workbench.js` 의 `STAT_NOTES`/`PLAN_METRIC_LABEL`,
   `candidates.js` 의 `GRADE_STYLE.label`/`VERDICT_PILL.text` 는 **모듈 로드 시점에 한 번만 평가되는 상수**였다.
   그대로 `t()` 를 넣으면 로드 시점 언어로 굳어 **언어를 바꿔도 안 바뀐다.**
   → 조회 **함수**(또는 키만 담은 맵)로 바꿔 호출 시점에 번역되게 했다. 표시 스타일(`cls`/`icon`)은 그대로 뒀다.

2. **`t` 이름이 지역 변수에 가려지던 3곳을 리네임했다.**
   `workbench.js` 의 `const t = r.timings` → `tm` (2곳), `history.js` `guessTitle()` 의 `const t = …tables…` → `tables`.
   리네임하지 않고 `t()` 를 넣었으면 **런타임에 "t is not a function" 으로 터졌을 자리**다.

3. **ko 표기가 통일되면서 일부 문구가 미세하게 바뀌었다** (중복 키 통합의 결과, 의도된 변경):
   - 이력 화면 검증 배지: `완전 동일`→`동일`, `집합 동일`→`순서다름`, `결과 다름`→`결과다름`, `비교 불가`→`확인불가`
     (후보 화면에서 쓰던 `verdict.*` 로 통합 — 두 화면이 같은 판정을 다르게 부르던 문제도 같이 해소).
   - 후보 권고 배너: `강력 권고`→`강력권고`, `검토 권고`→`검토`, `차이 미미`→`미미` (기존 `grade.*` 로 통합).
   - 원 조사 5절의 **항목 8("`library.js` 상태 라벨이 `history.js` 와 중복 정의")** 이 이걸로 해소됐다.
