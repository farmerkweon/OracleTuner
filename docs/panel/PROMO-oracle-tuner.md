## 2. 누구를 위한 도구인가

- **SQL 튜닝을 모르는 개발자.** 인덱스가 왜 안 타는지, 어떤 힌트를 써야 하는지 몰라도 씁니다. 도구가 여러 안을 만들고 직접 돌려서 어느 쪽이 빠른지 알려 줍니다.
- **운영 계정만 있는 사람.** DBA 권한이 없어도 됩니다. 지금 계정으로 뭘 볼 수 있는지 접속하자마자 확인하고, 안 되는 기능은 되는 선에서 최선으로 대신합니다.
- **오래된 Oracle을 쓰는 곳.** 11g 이하도 됩니다. 요즘 문법(`FETCH FIRST`)이 안 먹는 버전이면 예전 방식(인라인뷰+ROWNUM)으로 알아서 바꿔 돌립니다.
- **VDI·폐쇄망에서 일하는 개발자.** 인터넷이 안 되는 사내 PC에서도 압축만 풀면(또는 설치 파일 하나로) 바로 씁니다.

---

## 3. 왜 다른가 — 추측이 아니라 실행

SQL 튜닝 도구, 특히 요즘 AI 기반 도구는 대부분 "이렇게 바꾸면 빠를 것 같다"까지만 말해 줍니다. 코드를 보고 판단할 뿐, 실제로 돌려 보지는 않습니다.

Oracle Tuner는 다릅니다.

1. **직접 돌립니다.** 원본 SQL과 후보 SQL을 번갈아 여러 번 실행합니다. 한쪽만 먼저 여러 번 돌리면 뒤쪽이 캐시 덕을 봐서 더 빨라 보이는데, 순서를 계속 바꿔 가며 돌려서 이 문제를 없앱니다.
2. **끝까지 읽습니다.** 결과를 앞부분만 읽고 멈추면 안 됩니다. 전체 스캔 비용이 중간에 끊겨서 튜닝 전후가 똑같이 빨라 보이는 착시가 생깁니다. 그래서 끝까지 인출해서 잽니다. 최근에는 한 번에 읽는 행 수에 상한(최대 200만 행)을 두고, "실제로 읽은 행 수"와 "화면에 보여 준 행 수"를 나눠서 보여 줍니다. 숫자를 감추지 않는다는 뜻입니다.
3. **결과가 같은지까지 봅니다.** 빨라졌다고 끝이 아닙니다. 행 하나하나를 지문(SHA-256)으로 비교해서 원본과 같은 답을 내는지 확인합니다. 순서까지 같은지, 집합만 같은지도 구분합니다. **아무리 빨라도 결과가 다르면 순위에서 뺍니다.**

정리하면, 이 도구가 내는 숫자는 "그럴 것 같다"가 아니라 "직접 돌려서 쟀다"는 숫자입니다. 그게 이 도구의 진짜 값어치입니다.

## 4. 이번 버전 하이라이트 (3~4개만 앞세우기)

전체 변경 목록을 나열하지 말고 아래 넷만 앞세웁니다. 나머지는 "그 밖에" 항목으로 짧게 묶습니다.

### ① 설치 파일이 생겼습니다
지금까지는 압축을 풀고 `.bat` 파일을 눌러야 했습니다. 이번엔 진짜 설치 파일(exe) 하나로 됩니다. 실행하면 제일 먼저 언어부터 고릅니다(한국어/영어/일본어/중국어). 그다음 라이선스 동의, 설치 위치, 포트 지정을 지나 설치가 끝납니다. 콘솔 창은 안 뜹니다. 파일 크기는 31MB입니다.

### ② 테마가 화면 전체에 적용됩니다
전에는 표(그리드) 색깔만 바뀌었습니다. 이번엔 화면 전체가 바뀝니다. 8가지 테마가 있고, 그중 어두운 계열도 여러 개 있어서 밤에 작업할 때 눈이 덜 피곤합니다.

### ③ 토너먼트 진행 상황이 실시간으로 보입니다
후보 SQL을 여러 개 돌리다 보면 시간이 걸릴 때가 있습니다. 이번엔 지금 몇 번째 후보를 돌리고 있는지, 얼마나 남았는지 화면에서 바로 보입니다. 멈춘 건지 도는 중인지 몰라 불안할 일이 줄었습니다.

### ④ Oracle 11g 이하에서도 됩니다
`FETCH FIRST` 같은 12c 이후 문법은 예전 Oracle에서 안 먹습니다. 이제 버전을 보고 알아서 예전 방식(인라인뷰 + ROWNUM)으로 바꿔서 돌립니다. 오래된 Oracle을 쓰는 곳도 그대로 씁니다.

### 그 밖에 (짧게)
- 접속정보 저장 방식을 SQLite로 바꿨습니다. 암호는 그대로 암호화해서 저장하고, 용량은 추가로 안 듭니다(Node에 이미 들어 있습니다).
- 도움말에 그림으로 된 설계 문서가 들어갔습니다. 구조도 6종을 4개 언어로 다 볼 수 있습니다.
- 화면 전체 문구가 4개 언어(한/영/일/중)로 다 나옵니다.

## 6. 다운로드 안내 문구

**총괄 확인 필요:** 현재 빌드된 설치판은 `no-jre`(31MB) 하나뿐입니다. `with-jre`(Java 내장) 설치판도 같이 낼지 정해 주세요. 아래는 두 안입니다.

### 안내 문구 (설치판 하나만 낼 경우)

> **설치판 (권장) — 31MB**
> 다운로드한 exe를 실행하면 언어 선택부터 시작합니다. Java 11 이상이 이미 설치돼 있어야 합니다.
> 관리자 권한 없이도 설치됩니다(내 폴더에 설치할 경우).
>
> **포터블 — Java 포함판 / 기본판**
> 압축만 풀어서 쓰고 싶다면 포터블판을 받으세요. Java 포함판(약 62MB)은 Java 없이도 바로 됩니다. VDI·폐쇄망에 맞습니다. 기본판(약 42MB)은 Java 11 이상이 이미 있는 환경용입니다.

### 안내 문구 (with-jre 설치판도 함께 낼 경우 — 총괄이 빌드 후 사용)

> **설치판 — Java 포함 (권장, VDI·폐쇄망용)**
> Java가 없어도 바로 설치됩니다. 용량: 총괄 확인 필요.
>
> **설치판 — 기본판**
> Java 11 이상이 이미 있는 환경용. 31MB.
>
> **포터블판**
> 설치 없이 압축만 풀어서 쓰고 싶다면 이쪽입니다. Java 포함판(약 62MB) / 기본판(약 42MB).

## 7. 주의 · 한계 (숨기지 않고 그대로 적기)

- **베타입니다.** 도구가 후보를 만들고 성능·결과를 재서 근거를 보여 줄 뿐입니다. 운영에 반영하기 전에는 반드시 직접 확인하세요.
- **exe에 서명이 없습니다.** 다운로드하거나 실행할 때 Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄울 수 있습니다. 인증서를 아직 안 붙였기 때문입니다. 경고가 뜨면 "추가 정보" → "실행"으로 진행하시면 됩니다. 이 부분은 다음 버전에서 개선할 계획입니다.
- **Windows x64만 지원합니다.** 리눅스·macOS는 소스로 직접 실행해야 합니다.
- **일부 안내 문구는 아직 한국어만 있습니다.** 주요 화면은 4개 언어로 다 되지만, 세부 문구 일부는 아직입니다.
- **자동으로 만든 후보가 항상 맞는 SQL은 아닙니다.** 문법이 틀린 후보는 이유와 함께 표시되고, 다른 후보를 재는 데는 영향을 주지 않습니다.
